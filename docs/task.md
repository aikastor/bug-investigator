
# Capstone-проект:

### B2B SaaS & Consumer AI (Стартап-продукт)

Фокус на создании готового AI-first сервиса, готового к выводу на рынок и тестированию на первых пользователях.

#### 📍 Проект: Automated Bug Investigator & PR Reviewer (DevTools)

**Цель:** Создать агента-помощника для разработчиков, который автоматически разберет стек-трейс ошибки, найдет проблемный код в репозитории и предложит Pull Request с исправлением.

##### 📊 Критерии оценки проекта

| Критерий                         | Базовый уровень                    | Продвинутый уровень                                                                            |
| ---------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **Входные данные**    | Ручной ввод текста ошибки  | Автоматический прием Webhook из Sentry / GitHub Issues                                      |
| **Поиск кода**            | Поиск по ключевым словам    | Анализ структуры Git-репозитория и зависимостей через GitHub API     |
| **Тестирование**       | Генерация кода                      | Запуск локального тест-раннера в песочнице (Python REPL / Docker)           |
| **Инструменты (Tools)** | 1 инструмент (чтение файла) | Набор инструментов: GitHub API, Code Execution, Linter, Search                                  |
| **Результат**             | Текст в чате                           | Создание готового Pull Request в GitHub с подробным объяснением фикса |

##### 💡 Идеи для расширения

**Security Audit:** Дополнительная проверка предложенного кода на OWASP-уязвимости перед отправкой PR.

**Human Approval:** Уведомление разработчика в Telegram/Slack с кнопками "Одобрить PR" / "Отклонить".

**Оптимизация контекста:** Кэширование структуры репозитория для снижения расхода токенов.


# Техническое задание

## Автономные AI-Агенты и Мультиагентные Системы

### 1. Общие сведения

- **Тип проекта:** Autonomous Agent / Multi-Agent System / Copilot
- **Цель:** Создание интерактивной агентной системы для автоматизации комплексных бизнес-задач с вызовом внешних инструментов и принятием решений.
- **Ключевой фокус:** Готовность к эксплуатации в реальных условиях (Production-ready): надежный вызов инструментов (Function Calling), отслеживание траектории рассуждений (Observability), контрольные точки контроля человеком (Human-in-the-Loop) и обработка ошибок.

---

### 2. Архитектурные требования и слои системы

#### 2.1. Слой планирования и оркестрации (Orchestration & Logic)

- **Агентные паттерны:** Использование одного или комбинации паттернов: **ReAct**, **Plan-and-Execute**, **Reflexion** (самокритика).
- **Граф состояний (State Management):** Построение логики взаимодействия агентов через **LangGraph** или **LlamaIndex Workflows**.
- **Петля рефлексии (Self-Correction):** Наличие узла проверок, где агент оценивает свой промежуточный результат (например, валидность сгенерированного кода или факты из ответа) перед выдачей финального результата.

#### 2.2. Слой инструментов и внешних интеграций (Tools Layer)

- **Набор инструментов (Tools):** Подключение минимум 2-3 разнородных инструментов (Web Search API, Python Interpreter, GitHub API, SQL DB, Telegram/Email API).
- **Обработка ошибок инструментов:** Система должна уметь корректно обрабатывать таймауты и ошибки вызова API, возвращаясь на шаг перепланирования (Fallback mechanism).

#### 2.3. Слой контроля и взаимодействия (Human-in-the-Loop & UI)

- **Human-in-the-Loop (HitL):** Реализация точки паузы в графе (Interrupt) для подтверждения человеком критических действий (например, отправка писем, совершение финансовой транзакции, мерж PR).
- **Интерфейс пользователя (UI):** Разработка интерактивного веб-чата на базе **Streamlit** или **Chainlit** с отображением статуса агента («Агент ищет информацию в сети...», «Агент выполняет Python-код...»).
- **Наблюдаемость (Observability & Tracing):** Интеграция с **LangSmith** или **Weights & Biases** для отслеживания цепочки вызовов (traces), подсчета расхода токенов и отладки зацикливаний.

---

### 3. Технологический стек (Рекомендуемый)

- **Язык программирования:** Python 3.12+
- **Оркестрация агентов:** LangGraph / LangChain / LlamaIndex
- **LLM & Embeddings:** OpenAI API (GPT-6 \ 6.1) или Anthropic Claude 5 Sonnet / локальные LLM через Ollama
- **Observability & Tracing:** LangSmith
- **Фронтенд / UI:** Streamlit / Chainlit / Custom

---

### 4. Этапы и план разработки

- **Этап 1:** Проектирование архитектуры графа агента, определение Pydantic-схем для инструментов.
- **Этап 2:** Разработка узлов графа, интеграция инструментов (Tools) и базовое тестирование ReAct/Plan-and-Execute логики.
- **Этап 3:** Внедрение механизмов самопроверки (Reflexion) и точек остановки (Human-in-the-Loop).
- **Этап 4:** Разработка UI в Streamlit/Chainlit, подключение трейсинга в LangSmith.
- **Этап 5:** Тестирование сложных сценариев (Edge Cases), подготовка документации и презентации к защите.
